# Security policy

## Reporting a vulnerability in this repository

Please report vulnerabilities in the code in this repository privately, through GitHub's private
vulnerability reporting: open the repository's **Security** tab and choose
**Report a vulnerability**. Do not open a public issue for a security problem.

Include what is affected, how to reproduce it, and what an attacker could do with it. We will
acknowledge the report, keep you updated while we work on a fix, and credit you if you want.

## Problems with the hosted API

Security problems with the MolochAI API, the dashboard or your account are not handled here. Report
them through [molochai.dev/contact](https://molochai.dev/contact?utm_source=github&utm_medium=oss&utm_campaign=uncensored-llm-examples).

## API keys

Never post an API key in an issue, a pull request, a discussion or a log you share. If a key has been
exposed, revoke it in the [dashboard](https://dash.molochai.dev/account?utm_source=github&utm_medium=oss&utm_campaign=uncensored-llm-examples)
and create a new one; keys do not expire on their own and are not scoped.

## Supported versions

Only the latest commit on `main` is maintained.
